# 🐟 大肥鱼桌宠 v1.5.0 —— 优化清单第一批：更稳、更会记、AI 更听话

按「大肥鱼桌宠-优化清单」优先级实现的第一批改进（P0/P1 核心项 + P2 卫生）。

## 🛡️ 稳定性（P0-2 / P1-2 / P1-5）
- **静默异常收敛**：新增 `DFY_DEBUG=1` 调试开关（异常直抛）；日志写盘失败回退 stderr，不再无声吞掉
- **配置读取失败**会记日志并按默认值运行（以前是静默 pass）
- **动画单槽**：新动画启动前自动停掉上一个 tween，消除残留动画互相打架
- **退出守卫**：退出过程中在途的余额请求、气泡弹窗全部拦截，杜绝退出瞬间的异常

## 🧠 对话记忆持久化（P1-6）
- 聊天记忆写入 `memory.json`（原子落盘，最多 200 条），**重启后它还认得你**
- 记忆轮数可调：菜单「设置… → 🧠 对话记忆…」0~10 轮（0 = 不带记忆）
- 清除 API Key / 清理日志时记忆一并清除，语义干净

## 🤖 AI 可配置（P1-10）
- 菜单「设置… → 🤖 AI设置…」：接口地址（OpenAI 兼容，**支持本地 Ollama**）、模型名、人设提示词、回复字数、max_tokens 全部可改
- 内置默认仍是又娇又毒舌的大肥鱼人设（≤25 字贱萌，叫你「绳匠」）

## 🧹 日志卫生（P2-1）
- 脱敏升级：`?key= / api_key= / 字段形态` 等形式的 Key 也会被打码
- 菜单「设置… → 🧹 清理日志…」一键清空 error.log / memory.log / 对话记忆

## ✅ 工程化（P0-3）
- 新增 tests/ 单元测试 26 例（账本/情绪/帧动画/角色库/行走纯函数）+ GitHub Actions CI
- 每次提交自动跑 pytest + 126 项 offscreen 自检
