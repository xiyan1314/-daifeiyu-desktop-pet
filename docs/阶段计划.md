# 大肥鱼桌宠 v2 —— 阶段计划与验收文档

## 素材清单（已勘察）
- 帧序列（512×512，已透明）：v1_f00..f06 = 吃东西连续帧（7 帧）；v2_f00..f09 = 待机动作（10 帧）。
- 状态图（1024×1024，白底不透明，需去背景）：常态版 10 张（呼呼大睡/疑惑/哈气威胁/委屈哭泣/害羞脸红/开心大笑/得意坏笑/惊讶吃惊/猫式生气/馋到流口水）；吃饱版 7 张（呼呼大睡/疑惑/委屈哭泣/害羞脸红/开心大笑/得意坏笑/生气嘟嘟）。
- 音频：参考项目 DeepSeek-Balance-Whale-Widget 的 assets/Ya1.mp3（按压·小黄鸭）、Ya2.mp3（松手）、D1.mp3/D2.mp3（音效1）。

## 目标行为
1. 待机播放 v2 连续帧；长时间无交互进入呼呼大睡。
2. 吃东西播放 v1 连续帧；吃饱后切吃饱形态，12 秒消化回常态。
3. 戳一下→疑惑；短时间再戳→生气；生气时再戳→哈气威胁（戳链有冷却重置）。
4. 食物托盘打开→馋到流口水；托盘打开长时间不给吃→委屈哭泣。
5. 随机调皮事件→得意坏笑（做坏事）。
6. 按压/松手使用参考项目音频（转 WAV），缺文件时回退合成音效。
7. 退出：结束进程并清理残留（.tmp、过期 _MEI* 临时目录）。
8. 全程内存占用 < 1GB。

## 阶段划分与验收条目（R 编号供审查）

### 阶段 0 — 素材预处理（编排者执行，非代码阶段）
- R0-1 白底去背景：17 张状态图白色背景 flood-fill 变透明，并检测/去除角落水印残留（跨图同位置组件检测）。
- R0-2 命名规整：v1 → assets/eat_f00..f06；v2 → assets/idle_f00..f09；状态图 → assets/n_*.png（常态）/ f_*.png（吃饱），统一 512×512 透明。
- R0-3 音频：Ya1/Ya2/D1/D2 转 22050Hz 单声道 WAV → assets/sounds/ya1.wav 等。

### 阶段 1 — 帧动画系统（子agent 写码 → bug/符合性/质量审查）
新增模块 pet_anim.py，类 FrameAnim(QObject)：
- R1-1 add_set(name, [QPixmap]) 注册帧集；play(name, interval_ms, loops, on_finish) 播放；stop() 停止；current() 取当前帧；信号 frame_changed(int)。
- R1-2 PetWindow 集成：待机循环播放 idle（约140ms/帧）；进食播放 eat（约110ms/帧，播完回待机）；无交互 60 秒进入 sleep（呼呼大睡图 + zzz），有交互即醒来。
- R1-3 吃饱形态：进食后 form=full，待机显示 eat 末帧（或 f_ 状态图），12 秒消化回 normal。
- R1-4 帧缺失时回退原 character.png 静态图（兜底）。

### 阶段 2 — 戳戳情绪链与食物情绪（子agent 写码 → 审查）
新增模块 pet_mood.py，类 Mood(QObject)，信号 state/bubble/emote：
- R2-1 戳链：poke() 第 1 次→puzzled（疑惑图 2.5s+台词）；2.5s 内第 2 次→angry（生气图+怒气表情）；angry 期间再戳→hiss（哈气威胁图+台词）。超过冷却重置。
- R2-2 食物情绪：food_shown() → drool（流口水图+馋台词）；托盘开 8 秒未喂→cry（委屈哭泣+台词）；fed() 重置。
- R2-3 调皮事件：每 45~90 秒随机一次 smug（得意坏笑+做坏事台词）。
- R2-4 PetWindow 集成：单击（戳）转发到 Mood；托盘开关/喂食转发；状态图显示后自动回待机。
- R2-5 吃饱版缺图（哈气/流口水/惊讶）回退常态版同名状态。

### 阶段 3 — 音频 + 关闭清理 + 内存（子agent 写码 → 审查）
- R3-1 按压播 ya1.wav、松手播 ya2.wav、喂食播 d2.wav（资源缺失回退合成音效），音效开关仍生效。
- R3-2 退出清理：_quit 停止全部定时器、删除 config.json.tmp/usage.json.tmp、隐藏全部窗口、0.5s 后 os._exit(0)。
- R3-3 启动清理：删除 %TEMP% 下超过 1 天的 _MEI* 残留目录（异常退出遗留）。
- R3-4 内存：运行时 psutil 自测 < 1GB 并写入验证记录。

## 流程要求
每个阶段：子agent 按本文档写码 → bug 审查子agent → 文档符合性审查（按 R 编号逐条）→ 代码质量审查 → 全部通过才进下一阶段。
