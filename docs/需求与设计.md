# 大肥鱼桌宠 —— 需求与设计文档

版本：1.1.0
技术栈：Python 3.10 + PySide6（Qt6 框架，不使用 tkinter），PyInstaller 打包 exe。

## 1. 角色设定
- 名字：大肥鱼。
- 性格：又娇又耍赖、贪吃、被吓到就浑身发抖、任性可爱。
- 面对指控全程撒娇耍赖、拒不认罪。
- 名台词：喜欢的，就咬住不放~
- 角色图：透明 PNG，双形态（常态 / 吃饱）。用户可用 去背景.py 处理自己的图。

## 2. 功能需求清单（编号用于验收）
### 基础（必须）
- R1 去除图片背景：提供 去背景.py，输出透明 PNG；程序加载透明角色图。
- R2 窗口透明、无边框、始终置顶。
- R3 鼠标左键可拖动位置。
- R4 点击角色轮流触发互动：跳跃、压扁回弹、左右抖动、咬住。
- R5 互动时随机显示简短中文对话气泡；气泡背景不透明（白色）；气泡不遮挡角色（置于角色上方）。
- R6 右键菜单包含：调整大小、置顶开关、退出程序。
- R7 鼠标滚轮调整大小。
- R8 缺失依赖可安装；不使用 tkinter，使用 PySide6。
- R9 生成可执行 exe。

### 扩展（进阶）
- R10 三视图行走（正/左/右，运行时镜像 + 摆尾）。
- R11 跟随鼠标。
- R12 喂食（小鱼干 / 蛋糕 / 钻石）。
- R13 AI 对话（DeepSeek，每句不超过 25 字，贱萌）；右键菜单可填 DeepSeek API Key。
- R14 天气查询。
- R15 系统监控（CPU 超过 90% 冒泡提醒）。
- R16 启动方式：双击 启动桌宠.bat 或 python 桌宠.py。
- R17 MIT 开源。
- R18 双形态：常态（character.png / character_front.png）与吃饱形态（character_full.png / character_full_front.png）；喂食后切换为吃饱形态，约 12 秒后自动消化回常态；右键菜单可手动切换。
- R19 表情系统：互动时在角色头顶弹出表情符号（❤/✨/💦/💢/♪/💤/❗/❓），上浮渐隐动画。
- R20 DeepSeek 余额查询：右键菜单「查询余额」拉取 API 余额并气泡显示。
- R21 音效：互动/喂食播放合成音效（内存生成 WAV，免外部文件），菜单可开关。
- R22 四边吸附 + 按压 Q 弹：拖拽靠近屏幕边缘自动吸附；按住角色有压扁 Q 弹效果。
- R23 安全：API Key 用 Windows DPAPI 加密存储，磁盘不落明文；网络走 HTTPS + 超时。
- R24 喂食交互：右键菜单勾选「食物托盘」弹出托盘（小鱼干/蛋糕/钻石）；点击食物抛物线飞入口中；按住食物可拖到角色身上投喂。
- R25 戳戳情绪链：单击=戳 → 疑惑；2.5s 内再戳 → 生气；生气时再戳 → 哈气威胁；冷却重置。
- R26 帧动画：待机 v2 连续帧；喂食 v1 吃帧；60 秒无交互呼呼大睡；食物情绪（流口水/委屈哭泣）与调皮得意坏笑。
- R27 音频：按压 ya1 / 松手 ya2 / 喂食 d2（缺失回退合成音）；退出清理与启动残留清理；内存 < 1GB。
- R28 称呼与开场：台词称用户为「绳匠」；启动第一个表情为开心大笑（n_laugh）；被夸（菜单「夸夸她」或对话中含夸奖词）会害羞脸红（n_blush/f_blush）。

## 3. 架构
- PetWindow(QWidget)：主窗口（透明 / 无边框 / 置顶 / 拖动 / 滚轮 / 右键菜单）。
- QGraphicsView + QGraphicsPixmapItem：角色渲染与形变动画（视图对鼠标事件透明，事件直达主窗口）。
- Bubble(QWidget)：独立气泡窗口（背景不透明、不遮挡角色）。
- sprites 字典：normal / full 两套形态，每套含 side / front 两视图；运行时镜像实现左/右。
- 动画：QPropertyAnimation（窗口位移）、QVariantAnimation（形变）。
- 表情层：QGraphicsPixmapItem 叠加表情符号（QPainter 绘制），上浮渐隐。
- 音效：QtMultimedia QSoundEffect 播放 assets/sounds/*.wav（多音可叠加、不阻塞），
  不可用时回退 winsound 文件播放，再回退合成 WAV（pop/boing/feed）。
- 安全：Windows DPAPI（CryptProtectData）加密 API Key。
- 后台线程 + Qt 信号：天气、AI 对话、余额。
- 配置：config.json。
